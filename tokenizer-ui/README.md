# minbpe Tokenizer UI

An interactive, tiktokenizer-style visualizer for the **minbpe** Byte Pair Encoding library.
Built with **Next.js 14**, deployed on **Vercel**.

> **Live Demo** → _your-project.vercel.app_ (replace after deploy)

![minbpe Tokenizer UI screenshot](./public/screenshot.png)

---

## ✨ Features

| Feature | Details |
|---|---|
| 🎨 Token visualization | Each token gets a unique color, hover for ID + bytes |
| 📊 Live stats | Token count, character count, chars/token ratio |
| 🔄 Model selector | BasicTokenizer, RegexTokenizer (minbpe), GPT-4 cl100k, GPT-2 r50k |
| ⚡ Client-side BPE | minbpe tokenizers run entirely in the browser (no server round-trip) |
| 🌐 Server-side GPT-4 | GPT-4/GPT-2 tokenization via `/api/tokenize-gpt4` using `js-tiktoken` |
| 📱 Responsive | Works on mobile & desktop |

## 🚀 Quick Start (Local)

### Prerequisites

- **Python ≥ 3.9** with `pip`
- **Node.js ≥ 18** with `npm`

### Step 1 — Install Python dependencies

```bash
# From the project root (nlp-project/)
pip install regex tiktoken
```

### Step 2 — Add your training data

Open `tests/taylorswift.txt` and paste in your corpus text.
The more text, the better the tokenizer (aim for at least 1 MB for vocab_size=50000).

```bash
# Quick check
python -c "print(open('tests/taylorswift.txt').read()[:200])"
```

### Step 3 — Train the tokenizers

```bash
# From the project root (nlp-project/)
python train_tokenizer.py
```

This trains **BasicTokenizer** and **RegexTokenizer** at `vocab_size=50000` and writes:
- `tokenizer-ui/public/models/basic_tokenizer.json`
- `tokenizer-ui/public/models/regex_tokenizer.json`

> ⏱️ Training time depends on dataset size. A 1 MB corpus takes ~30–120 seconds per tokenizer.

### Step 4 — Run the web app

```bash
cd tokenizer-ui
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) 🎉

## 🏗️ How Training Works

`train_tokenizer.py` uses the **minbpe** library to:

1. Read `tests/taylorswift.txt` as UTF-8 text
2. Train `BasicTokenizer` (plain BPE, no regex) for 50,000 vocab
3. Train `RegexTokenizer` (GPT-4 split pattern + BPE) for 50,000 vocab
4. Serialize both tokenizers to JSON with:
   - `merges` — list of `[p0, p1, new_idx]` triples (the BPE merge rules)
   - `vocab`  — dict of `idx → byte_array` for every token

The JSON is loaded client-side by the JavaScript BPE implementation in `lib/tokenizer.js`.

## ☁️ Deploying to Vercel

### Option A — Vercel CLI (recommended)

```bash
# Install Vercel CLI once
npm install -g vercel

# From the tokenizer-ui/ directory
cd tokenizer-ui
vercel

# Follow prompts:
#   Set up and deploy? → Y
#   Which scope?       → your-account
#   Link to existing?  → N  (new project)
#   Project name?      → minbpe-tokenizer
#   Directory?         → ./  (current)
```

After first deploy, push updates with:
```bash
vercel --prod
```

### Option B — GitHub + Vercel Dashboard

1. Push the entire `nlp-project/` repo to GitHub
2. Go to [vercel.com/new](https://vercel.com/new)
3. Import the GitHub repo
4. **Set Root Directory** to `tokenizer-ui`
5. Framework preset: **Next.js** (auto-detected)
6. Click **Deploy**

> **Important:** The trained model JSON files (`public/models/*.json`) must be committed to Git before deploying. Vercel does not run Python — training must happen locally first.

### Environment Variables

No environment variables are required for basic operation.

If you add authentication or analytics later, set them in the Vercel Dashboard → Settings → Environment Variables.

## 🔄 Re-training & Updating Models

After editing `tests/taylorswift.txt` (or changing `VOCAB_SIZE` in `train_tokenizer.py`):

```bash
# 1. Re-train
python train_tokenizer.py

# 2. Commit the new JSON files
cd tokenizer-ui
git add public/models/
git commit -m "retrain: updated tokenizer models"
git push

# 3. Vercel auto-deploys on push (if GitHub connected)
#    Or manually: vercel --prod
```

## 🧩 Adding a New Tokenizer

1. **Train it** in Python and export via `tokenizer_to_json()` in `train_tokenizer.py`
2. **Copy the JSON** to `tokenizer-ui/public/models/your_tokenizer.json`
3. **Register it** in `tokenizer-ui/lib/registry.js`:

```js
{
  id: "your_tokenizer",
  label: "Your Tokenizer (minbpe)",
  group: "minbpe — Custom Trained",
  type: "basic",          // or "regex"
  modelPath: "/models/your_tokenizer.json",
  description: "Trained on ...",
}
```

4. It will automatically appear in the dropdown. ✅
